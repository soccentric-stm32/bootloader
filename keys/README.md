# Image signing keys (BSAFE-006)

BOOT accepts only images signed with ECDSA P-256 by the key whose public
half is compiled into it.

| File | Purpose |
| --- | --- |
| `dev-signing-key.pem` | **Published development key.** Anyone can sign images with it. Use it on the bench only. |
| `dev_pubkey.c` | Its public key as C, generated by `tools/mkimage.py --export-pubkey`. The default `BOOT_SIGNING_KEY_SOURCE`. |

The build prints a CMake warning whenever BOOT trusts the development key.

## Signing an image

```bash
# while wrapping a .bin
tools/mkimage.py --input app.bin --output app.img --version 1.4.0 \
    --key keys/dev-signing-key.pem --security-counter 2

# or sign an image an application build already produced
tools/mkimage.py --sign app.img --key keys/dev-signing-key.pem \
    --security-counter 2 --output app-signed.img

tools/mkimage.py --inspect app-signed.img --key keys/dev-signing-key.pem
```

The signature covers header bytes 0..127, which include the SHA-256 of the
binary, so changing either the header or the image breaks it.

## Anti-rollback

`--security-counter` is independent of the semantic version.  Once the
application confirms an image, BOOT refuses any image with a lower counter,
and the older image in the other slot is no longer bootable.  Raise the
counter only for releases that fix a security problem, because every image
below it becomes unusable on devices that have confirmed the new one.

## Product keys

```bash
tools/mkimage.py --genkey /secure/product-signing-key.pem
tools/mkimage.py --export-pubkey /secure/product-signing-key.pem \
    --output /secure/product_pubkey.c
cmake -S . -B build -G Ninja \
    -DBOOT_SIGNING_KEY_SOURCE=/secure/product_pubkey.c
```

Keep the private key out of this repository (`.gitignore` ignores every
`*.pem` except the development key) and preferably in an HSM or CI secret
store.  The `.c` file holds only the public key.  `bootctl.py info` shows
the key id BOOT trusts.

Signing protects the UART update path and the boot-time check.  Without
read-out protection, anyone with SWD access can replace BOOT itself.

A bench build that accepts unsigned version 1 images is available with
`-DBOOT_SIGNED_IMAGES=OFF`.
